## 1. 安裝（每台電腦一次）

### 自動設定（建議）
直接雙擊 **`start_viewer.bat`** 或 **`convert.bat`**，第一次會自動完成以下兩步，不用打指令：
1. 找不到 Pixi 時詢問「要現在自動安裝嗎 [Y,N]?」→ 按 **Y**
2. 自動建立執行環境（依 `pixi.lock` 安裝與負責人相同版本的套件，約 3～10 分鐘）

完成後就會直接開啟圖台或開始轉檔；之後再開就不用再等。
若自動設定失敗（例如公司網路擋住下載），畫面會顯示錯誤訊息，請截圖給負責人，或改用下面的手動步驟。

### 手動設定

#### 1.1 安裝 Pixi
1. 按 `Win + X`，選「終端機」或「Windows PowerShell」。
2. 貼上下列指令後按 Enter：
   ```powershell
   iwr -useb https://pixi.sh/install.ps1 | iex
   ```
3. 看到安裝完成訊息後，**關閉這個視窗，再重新開啟一個新的 PowerShell**（新的視窗才找得到 `pixi` 指令）。

#### 1.2 建立執行環境
1. 在 PowerShell 切換到本專案資料夾（就是有 `pixi.toml` 的那個資料夾），例如：
   ```powershell
   cd D:\Tools\Delft3dfm-1D2D-viewer
   ```
2. 執行：
   ```powershell
   pixi install
   ```
   第一次約需數分鐘，完成後就可以開始使用。

## 2. 轉檔：NC → Zarr / GeoTIFF

### 2.1 最簡單的方式：雙擊 `convert.bat`
1. 雙擊本專案資料夾裡的 **`convert.bat`**。
2. 把 Delft3D-FM 的成果資料夾（裡面有 `XXX_0000_map.nc`、`XXX_0000_fou.nc`…），或整個模型專案資料夾（程式會自動往下層找 .nc），**拖曳到黑色視窗**，按 Enter。
3. 詢問輸出資料夾時，直接按 Enter 會輸出到「放 .nc 的成果資料夾 + `\ZARR`」（例如 `D:\模型\MyModel\output\ZARR`），不會和模型輸入檔混在一起。
4. 看到「🎉 全部完成！」就完成了。

### 2.2 指令方式
在 PowerShell（本專案資料夾）執行：
```powershell
pixi run convert -i <成果資料夾> [-o <輸出資料夾>] [--res <解析度>] [--cog-only] [--crs <坐標系>]
```

| 參數 | 必填 | 預設 | 說明 |
|---|:---:|---|---|
| `-i`, `--input-dir` | 是 | — | 成果資料夾。先找資料夾本身，找不到才往子資料夾找。若子資料夾內有多組成果（例如多次模擬），會停止並請你指定正確的資料夾。 |
| `-o`, `--output-dir` | 否 | 同輸入資料夾 | 輸出位置 |
| `--res` | 否 | 自動 | 輸出柵格解析度（公尺）。自動模式會取「最小的常見網格寬度」，例如 5/10/40 m 加密網格會用 5 m。 |
| `--cog-only` | 否 | — | 只產出最大淹水深度 GeoTIFF，不產出逐時 Zarr（速度快很多，適合只要淹水圖時使用）。 |
| `--crs` | 否 | `EPSG:3826` | **只在 NetCDF 檔內讀不到坐標系時才使用**。正常情況下會自動讀取檔案內的 EPSG 代碼。 |

#### 範例
```powershell
# 一般轉檔
pixi run convert -i "D:\模型\MyModel"          # .nc 在 MyModel\output → 結果放在 MyModel\output\ZARR

# 只要最大淹水深度 GeoTIFF
pixi run convert -i "D:\模型\MyModel\output" -o "D:\GIS\MyModel" --cog-only
```

### 2.3 轉檔做了什麼
- **檔名不拘，依內容判讀**：程式會打開資料夾內每個 `.nc` 檔判斷種類，檔案改過名也沒關係（例如 `颱風A_最大水深_3.nc`）：
  - 含 `Mesh2d_fourier…` 變數 → fou 檔
  - 含隨時間變化的 `Mesh2d_waterdepth`／`Mesh2d_s1` → map 檔
  - his、rst、雨量檔等其他 NetCDF → 自動略過
  - **分區編號**取自檔案內的 `Mesh2d_flowelem_domain`，不看檔名。若檔名含 `_0003_` 之類的編號但與內容不符，畫面會顯示 ⚠️ 提醒，並以內容為準。
- **支援中文路徑**：資料夾或檔名含中文都可以（例如 `D:\模型\颱風事件\成果`）。
- **排除重疊格**：平行計算時，每個分區檔都會包含鄰區的一圈網格（ghost cells）。轉檔時依 `Mesh2d_flowelem_domain` 只保留各分區自己負責的網格，所以合併時不會重複。
- **以網格多邊形柵格化**：每個網格面依實際形狀塗進柵格，三角形、四邊形與局部加密網格都不會出現破洞。
- **最大淹水深度來源**：優先使用 fou.nc 中 long_name 為「water depth, maximum value」的變數（.fou 設定 `wd max`）。若沒有，改用 `water level` 的 `_max_depth`。沒有 fou.nc（或 fou.nc 內沒有水深最大值）時，則取 map.nc 全時段的最大值。
- **記憶體**：逐時水深每次只讀 8 個時間步，大檔案也不會一次塞滿記憶體。

### 2.4 產出檔案

| 檔案 | 說明 |
|---|---|
| `XXX_000N_map.zarr`（資料夾） | 各分區逐時水深，維度 `(time, y, x)`，變數 `Mesh2d_waterdepth`。圖台讀這個。 |
| `XXX_000N_fou_max_depth_cog.tif` | 各分區最大淹水深度（Cloud Optimized GeoTIFF，含金字塔） |
| `XXX_max_depth_merged_cog.tif` | **全區合併**最大淹水深度，可直接拖進 QGIS／ArcGIS |
| `partitions_metadata.json` | 坐標系、解析度、各分區檔案清單 |
| `mesh1d.zarr`（資料夾）、`mesh1d_network.geojson` | 1D 渠道／管線的逐時數值（水深、水位、地面溢淹水深、流量）與線形；GeoJSON 可直接用 QGIS 開啟 |
| `his.zarr`（資料夾）、`his_objects.geojson` | 觀測站、抽水站、閘門、堰、橋梁、觀測斷面等（依 his.nc 內容自動辨識）的時序與位置；GeoJSON 含檢核摘要（抽水站是否運轉、是否滿載、最大流量等），可用 QGIS 開啟 |

GeoTIFF 說明：網格外為 NoData（-9999），乾地為 0。

## 3. 展示圖台操作

### 3.1 開啟
- 雙擊 **`start_viewer.bat`**，或在 PowerShell（本專案資料夾）執行 `pixi run viewer`。
- 瀏覽器會自動開啟 `http://127.0.0.1:8088/`。8088 被占用時，會自動改用 8089、8090…（請以黑色視窗上顯示的網址為準）。
- **黑色視窗不要關**；要結束圖台時，在黑色視窗按 `Ctrl + C`。

進階啟動參數：
```powershell
pixi run viewer --data "D:\模型\MyModel"       # 啟動時直接載入
pixi run viewer --port 9000                    # 指定連接埠
pixi run viewer --host 0.0.0.0                 # 讓同一區網的其他電腦也能開（請注意成果資料保密）
pixi run viewer --no-browser                   # 不自動開啟瀏覽器
```

### 3.2 載入成果
- 按「📂 點選瀏覽資料夾」會跳出 Windows 選擇資料夾視窗，選好後會自動載入；或
- 在「資料夾路徑」欄位貼上完整路徑，按 Enter 或「🔄 載入／重新掃描」。

可以選**轉檔後的 Zarr 資料夾**，也可以直接選 **Delft3D-FM 原始成果資料夾**（含 map.nc / fou.nc）：

| 選到的資料夾 | 圖台的動作 |
|---|---|
| 含 `.zarr` | 直接載入 |
| 原始成果，第一次開啟 | 自動轉檔（畫面顯示進度），完成後自動載入 |
| 原始成果，之前已轉過且原始檔沒變 | 直接載入上次的轉檔結果，不用再等 |
| 原始成果，原始檔有更新（重跑模擬） | 自動重新轉檔 |
| 只有 fou.nc、沒有 map.nc | 顯示說明：圖台需要 map.nc 的逐時水深 |

自動轉檔的結果放在 .nc 所在成果資料夾底下的 **`ZARR`**（與 `convert.bat` 相同；可選整個模型專案資料夾，程式會往下層找 .nc）；舊版放在旁邊 `<資料夾名稱>_ZARR` 的結果仍可沿用；若該位置沒有寫入權限（例如唯讀的網路磁碟），改放在本機 `%LOCALAPPDATA%\dfm_viewer\cache\`。同一時間只會執行一個轉檔工作。

### 3.3 功能
| 功能 | 操作 |
|---|---|
| 底圖切換 | 臺灣通用電子地圖、正射影像、CartoDB 暗色、OpenStreetMap（需連網） |
| 分區開關 | 側邊欄逐一勾選／取消各分區的水深圖層與外框 |
| 套疊向量 | 上傳 GeoJSON（例如河道、抽水站、村里界；坐標須為經緯度 WGS84） |
| 時間播放 | 底部 ▶ 播放／⏸ 暫停，或拖曳時間滑桿；時間格式 `MM-DD HH:mm` |
| 點位查詢 | 點地圖任一處，取最近的柵格點顯示水深歷線；位於分區交界時，同時顯示各分區曲線與逐時最大值 |
| 1D 渠道／管線 | 側邊欄「〰️ 1D 渠道／管線」：開關圖層、選擇顯示項目（水深／水位／地面溢淹水深／流量）、勾選「全時段最大值」。線段依網路實際線形繪製，暖色系（黃→紅）與 2D 藍色區隔；流量使用對數色階，河道與下水道可同時辨識。點擊線段顯示管段編號與該段歷線 |
| 觀測站與結構物 | 側邊欄「🏭 觀測站與結構物」：各類別可個別開關（S 觀測站、P 抽水站、G 閘門、W 堰、B 橋梁、紅線＝觀測斷面）。抽水站標記隨時間軸變色：**綠＝運轉中、灰＝停機、灰色虛線框＝整場未運轉**。點擊標記顯示目前／整場最大值，並畫出歷線（左軸流量、右軸水位；抽水站含設計容量虛線與吸水側／出水側水位）。可用「搜尋名稱」直接定位；同一位置的多個物件會左右錯開 |
| 檢核摘要 | 同一區塊下方自動列出：抽水站運轉座數與滿載座數、**整場未運轉的抽水站清單**（點名稱可跳到該站）、觀測站最大水深、質量平衡誤差（佔總水量百分比） |
| 色階／透明度 | 標準藍色系或藍-黃-紅警示色系、整體透明度、是否顯示 0.1～0.3 m 淺積水 |

## 5. 常見問題

**Q1：PowerShell 說找不到 `pixi`？**
安裝完 Pixi 後要關掉 PowerShell 重開。還是不行的話，請重新執行 1.1 的安裝指令。

**Q2：轉檔出現「分區 [0000] 找到不只一個 map.nc」？**
`-i` 指定的資料夾裡（含子資料夾）有不只一次模擬的成果。請改成指定到只含單次成果的那一層，例如 `...\dflowfm\output`。

**Q3：轉檔出現「找不到 2D 最大水深變數」？**
fou.nc 裡沒有水深最大值，而且資料夾裡也沒有同分區的 map.nc 可以替代。請確認 `.fou` 檔有設定 `wd ... max` 或 `wl ... max`。
（有 map.nc 時，程式會自動改用 map.nc 全時段最大值，並在畫面上顯示 ⚠️ 提示。注意：map.nc 只有輸出時刻的水深，算出的最大值通常比 fou.nc 略小。）

**Q4：點地圖沒有跳出歷線圖？**
點到的位置不在模式網格範圍內，就會顯示「該點位無水深資料」。

**Q5：底圖一片空白？**
底圖需要連上網路（內政部國土測繪中心 WMTS、OpenStreetMap）。淹水圖層不需要網路。

**Q6：1D 圖層沒有出現？**
側邊欄沒有「〰️ 1D 渠道／管線」區塊，代表這份成果的 map.nc 沒有 1D 網路，或是用舊版程式轉的檔。直接選原始成果資料夾，圖台會自動以新版重新轉檔（舊版轉檔結果會被判定為過期）。灰色細線代表該時刻沒有水（低於 0.01）。

**Q7：沒有「🏭 觀測站與結構物」區塊？**
成果資料夾裡找不到 his.nc（平行計算時通常是 `XXX_0000_his.nc`），或是用舊版程式轉的檔。請確認 his.nc 與 map.nc 放在同一個資料夾，再直接選原始成果資料夾讓圖台重新轉檔。

**Q8：抽水站／閘門的位置和 Delta Shell 裡看到的不一樣？**
彈出視窗最下方會註明位置依據：
- 「管段 XXX 里程 N m（structures.ini 設計位置）」：與 Delta Shell 相同的設計位置。
- 「模式計算位置」：找不到 `structures.ini`，改用 his.nc 的座標。D-Flow FM 會把結構物吸附到最近的 1D 計算連線，his.nc 記錄的是該連線中點，計算點間距越大偏差越大（實測可達 40 m 以上）。

轉檔時會從成果資料夾往上找 `.mdu`，讀取其中的 `StructureFile`。若成果資料夾是單獨複製出來的（旁邊沒有 .mdu），請把**該次模擬使用的** `structures.ini` 放進成果資料夾，或在指令加上 `--structures 路徑\structures.ini`。版本不同的 structures.ini 可能有管段對不上，對不上的結構物會自動改用 his.nc 座標。
